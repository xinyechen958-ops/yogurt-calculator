① 原料库 改价格即全局生效

按「规格 + 单价」录采购价，自动换算单位成本；水果涨价直接改采购价即可。列表按分类分组，改一条的分类会自动归到对应组。

原料名称 分类 采购规格 单位 每件≈ 采购价 ¥ 单位成本 备注
单位成本怎么算
单位成本 = 采购价 ÷ 规格数量。酸奶、牛奶等液体可用 ml（1ml ≈ 1g）。
按「个/份」采购的原料（如柠檬、鸡蛋），可在「每件≈」填一件大约多少 g，配方里就能按「个」或按「g」两种计量方式输入，成本自动换算。

② 自制库 一锅一锅做的半成品

按四类分开管：自制酸奶底（原味/希腊/椰子…）、自制果酱、自制麦片、自制冻冻。填投料 + 每批产出量，自动算出品率和每克成本；在配方里就能像原料一样直接取用。投料也是打字搜索，不用在长列表里翻。

改动会自动存本机；点「保存并同步」可立刻上传到云端
出品率和单位成本怎么算
投料总量 = 各行用量折算成 g 后相加（按「个」投料的会乘上「每件≈」的克数）。
出品率 = 每批产出量 ÷ 投料总量。5L 牛奶出 4.6kg 酸奶，就是 92%，损耗已经摊进单价了。
每批总成本 = 投料成本 + 其它耗材（菌种、滤网等没进原料库的）。
单位成本 = 每批总成本 ÷ 每批产出量。产品用了自制半成品，用量会自动折回牛奶、菌种等原料上，采购量和涨价模拟都按这个算。

③ 配方与单碗成本 按产品配置用量

产品按 酸奶碗 / 酸奶昔 / 三明治 分组；展开卡片，在「分类」里可以把它挪到别的组，也可以直接点各组的「+ 新增」。用量单位与原料库一致；按「个」采购又按「克」用的原料，可切换单位。明细默认收起，点箭头展开编辑。原料多的时候，直接在「加入配方」框里打字搜名称（或分类，如「水果」）。

⑧ 调价记录

每次修改采购价会自动留痕，方便回头核对是哪些原料在推高成本。

⑨ 云端同步 未开启

开启后，电脑和任意几台手机都读写同一个私有仓库里的数据文件：改一处，其他设备下次打开就是最新数据。

首次配置：三步开启同步
1. 新建私有仓库：名字填 yogurt-data，选 Private，不要勾任何初始化选项
2. 生成 token：Only select repositories 只勾刚建的仓库 → Permissions 里 Contents 设为 Read and write → 有效期建议 1 年
3. 把仓库名和 token 填进下面两栏，点「保存并启用」
建议先在平时用的主力设备上开启，把它的数据当起点；另外几台填同样的仓库和 token 即可。
未开启云端同步 —— 数据只存在这台设备的浏览器里。
同步链接 · 换设备不用再填 token

把仓库和 token 藏进网址的 # 后面。任何手机、任何浏览器、微信里打开这条链接，都会自动连上云端这份数据 —— 手机和电脑看到的永远是同一份。

链接只在你自己手里，# 后面的内容不会发给任何服务器。存进手机备忘录即可。
顺序很重要：先在存着真实数据的那台设备上开启同步并上传，再把生成的链接拿到别的设备打开。
云端快照 · 覆盖错了还能翻回来

每次要用这台设备的数据覆盖云端之前，会先把云端现有版本另存一份到仓库的 history/ 目录，最多留 30 份。两台设备各改各的也不会丢东西。

⑩ 备份与打印

导出/导入是「手动搬运」，适合没开云端同步时换设备，或做一份离线存档。

导出 Excel（CSV）：中文表头的表格，Excel / WPS / 数字表格都能直接打开，含原料、产品、配方明细、固定成本、最近记账 —— 哪天不用这个工具了，数据也带得走。
下载离线副本：把当前数据嵌进一份网页文件存到本地，断网、GitHub 打不开时也能看。存进手机文件里当保命副本。
添加到手机主屏幕：安卓 Chrome 打开页面后，点右上角「⋮」→「添加到主屏幕」，桌面就会多一个图标，点开即用。
提示：本地文件打开的页面，部分浏览器会把它加为「书签快捷方式」而不是独立 App 窗口，功能完全一样。
